# 技能评估、审查证据与会话执行保护

## 三种结论分别展示

- 文档检查仅报告当前输入中是否存在代码示例、验收章节、注意事项与编号步骤。没有总分，也不把这些格式特征解释为正确性或能力提升。
- 效果未经过真实任务对照测试时，明确标记“效果未验证”。内置目录模板与实际安装文件分别标识；实际文件无法读取时，不使用模板冒充。
- 安全审查是对一个明确文件快照的风险筛查。审查通过不表示运行安全，也不代替执行权限限制。

目录里的权限字段只是未独立验证的用途提示，不是执行授权或权限上限；缺失时显示“未记录”，不默认声称仅需文件权限。实际限制以所选会话的工具保护为准。

## 完整目录证据

目录核验包含隐藏项、配套文件、相对路径、文件类型、权限和实际内容哈希。读取失败、链接、特殊文件、未知或不可审查的格式以及超限内容不会退化为只检查 `SKILL.md`。

面板状态包括：未审查、审查记录有效、内容已变化、无法核验、审查已过期和审查拒绝。有效记录需要同时满足完整目录指纹一致、审查策略和提示词一致、未过期且审查结论允许。历史 `auditVerdict` 字段不单独构成有效证据。

手动复审必须明确选择一个有效模型会话。复审前后再次核验目录；期间文件发生变化时，结果不能绑定为当前有效。修改正文、配套脚本、文件清单或权限会使旧证据失效。

插件自身确定性的启停、改名操作只有在变换前证据有效，并核实变换后恰好只有指定元数据变化时才可派生证据；不延长原审查期限。它不会忽略这些字段，也不能借此接受其他正文或配套文件变化。

## 会话工具保护

保护以明确选择的会话为单位。默认只读；允许工作区写入需要用户在页面中明确选择。安装前审查与会话工具保护分别显示，不能互相替代。

执行保护使用宿主的工具执行拦截接口，按工具和参数强制拒绝；不根据模型是否承诺遵守来放行。不支持强制执行接口的宿主不得显示已保护。

首版受限工具面面向本地文件读写工作流：限制文件访问范围，拒绝敏感路径、路径穿透和控制面修改，并拒绝 shell、交互终端、网络、任意代码、子代理及未知工具。保护模式会限制需要执行脚本或联网的技能，不能把这种限制隐藏为技能成功。

当前适配经过核实的 DSH 原生工具模式。PTC 任意代码通道、缺少必要执行接口或无法核验的工具定义均显示不可用。宿主重载或首次开启时，若会话历史已有无法可靠重建的技能/任意代码加载记录，需要使用新会话；不会把旧历史内容自动视为新审查通过的内容。

启动恢复完成前，持久化的保护选择尚未知晓，因此会暂缓所有工具调用。保护状态损坏或无法读取时，这个暂停会持续并显示原因，需要先恢复状态文件或其 `.bak` 备份；不会把读取失败当作所有会话均未开启保护。

## 已知边界与验证含义

- 模型审查仍可能误判；分段覆盖内容不等于证明跨文件组合行为安全。
- 回归测试验证状态与拦截逻辑，不提供恶意样本检出率或技能实际效果评分。
- 工具拦截约束经过宿主工具执行链的调用；不隔离宿主插件自身、其他进程或用户直接运行的程序。
- 网络拒绝针对工具调用通道；不覆盖模型文本输出、客户端内容渲染或其他宿主插件自行产生的网络请求，不能称为系统级网络隔离。
- 保护信任当前宿主工具注册表和已安装的宿主插件。它不能认证或隔离已获得同进程 Node.js 权限的恶意插件。
- 路径核验与后续工具打开文件之间仍存在其他进程并发替换文件的竞态。需要操作系统级隔离才能进一步约束此类威胁。
- 保护只作用于已开启的会话，不能理解为整台电脑或所有其他会话均处于沙箱中。
- 文档、脚本或远端依赖后续变化需要重新评估；一次安装审查不保证今后下载的内容。
